# Raw data provenance

`internship_postings.csv` contains 15 real internship listings collected from
public company career pages on August 24, 2026.

- `description` is a concise, skill-focused paraphrase of the source listing,
  not a copy of the full job description.
- `source_url` points to the public listing used for each record.
- A listing being present in this dataset does not guarantee that applications
  remain open; company career pages can change after collection.
- The dataset is intended for educational analysis and should be refreshed
  before drawing conclusions about the current job market.
